# おやすみグレー for Windows 実装計画

実装当時の計画と残る実機確認項目です。現在の確認結果は [検証状況](verification.md) を参照してください。

**目標:** Windows 11 x64 の通常のデスクトップを指定時刻から徐々にグレースケールへ変え、朝に解除する常駐アプリを作る。

**設計:** [Windows アプリ設計書](design.md)。時刻計算と色行列を OS 非依存の Core に分け、WinForms が設定・通知領域・Windows API を扱う。

**技術:** .NET 10、C#、WinForms、Magnification API。Windows 11 x64 の SDR 画面を初版対象とする。

## 手順

- [x] Core の設定検証、日時計算、行列、競合制御の失敗するテストを書く。
- [x] Core を実装してテストを通す。
- [x] Windows API の薄いアダプター、JSON 永続化、起動登録を実装する。
- [x] 通知領域 UI と状態管理を接続する。
- [x] Windows 用にビルド・発行し、Core テストを実行する。
- [x] Windows 実機で中間色の見え方、ロック・スリープ復帰、通知領域からの停止・終了を確認する。
- [x] Windows 実機で各モニターへの適用と、画面構成の変更後の動作を確認する。
- [ ] Windows 実機で朝の指定時刻の復帰を確認する。

レビューでは、夏時間、停止時の他アプリへの上書き、保存中の連打、クラッシュ後の行列、通常権限の Windows 実機適用を重点的に確認する。
